# Beta 就绪评估 · Beta Readiness

## 结论：有条件可以（建议 Closed Beta / 内部测试）

## 可进入哪种 Beta

- **首选**：内部测试（10–30 名玩家）→ 修复高优项后 → **Closed Beta**。
- **不建议直接 Open Beta**：新功能（心愿单 / 借还 / 购买清单）仅近期新增、未大规模实战；多设备同步未实现；无自动化测试兜底。

## Beta 前必须修复（阻塞项）

1. 新功能删除操作补 `ask()` 确认（wishlist / loans / purchase-lists 及其条目）。
2. 修复 `/simulator` 死链（删除导航项或建占位页）。
3. 处理「已买到 / 标记已拥有」与收藏库存的同步：最小方案 = 提示文案；推荐 = 提供「一键写入收藏」按钮。
4. 验证并明确告知**备份/恢复**的正确使用流程（换机/重装前必须备份）。
5. `pnpm check` + prettier 全绿（当前已满足）。

## Beta 期间可接受的问题

- 借还 / 心愿单 / 清单的交互细节不够顺手（收集反馈迭代）。
- 大陆网络下卡图加载慢/失败（已有 fallback 蓝图 + README 提示）。
- 大数据量下缺卡 / 清单查询变慢（关注并报告）。
- TTS 连通性失败（TTS 未运行属正常，已有优雅降级）。

## Beta 不建议开放的功能

- **TTS 联动**（依赖外部 Tabletop Simulator，非目标用户核心诉求）。
- **多设备同步**（未实现，勿宣传）。
- 若 Android 未完整回归，**Android 包不开放**。

## Beta 用户需要知道的事项

- 所有数据保存在**本机**，换设备/重装前请先在设置页**备份数据库**。
- 购买清单「已买到」目前**不会自动计入收藏**，需手动录入（后续版本自动写回）。
- 首次使用需联网同步卡牌数据（离线可用，但卡库为旧版）。
- 新功能（心愿单 / 借还 / 购买清单）处于早期版本，遇问题请通过设置页反馈文档提交。
- 本项目为第三方社区工具，非 Riot 官方。

## 建议收集的反馈指标

| 指标                                      | 目的           |
| ----------------------------------------- | -------------- |
| 缺卡检查准确率（print / card 两种模式）   | 核心正确性     |
| 购买清单生成/刷新使用次数 + bought 转化率 | 功能价值验证   |
| 借出/借入创建与归还次数、逾期率           | 借还模块活跃度 |
| 数据丢失 / 误删事件报告数                 | 风险监控       |
| 崩溃 / 白屏日志（经反馈渠道）             | 稳定性         |
| 卡库同步失败率、首次同步耗时              | 内容分发健康度 |
| 搜索零结果率                              | 搜索质量       |
| NPS / 试用后访谈                          | 整体留存       |
