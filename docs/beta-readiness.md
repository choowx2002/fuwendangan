# Beta 就绪评估 · Beta Readiness

## 结论：有条件可以

核心业务闭环（收藏 → 借还 → 卡组持有检查 → 购买清单 → 已购写回）**已完整实现**，`pnpm check` 0 错误 0 警告，删除均有确认，重复插入已由唯一键防住，借还已正确计入可用库存。主要风险集中在「数据安全兜底」与「同步/发布运维」层面，**修复少数阻塞项后即可进入小范围封闭测试**。

## 可以进入哪种 Beta

- **推荐路径**：内部测试（10–30 名玩家，先于 Closed Beta）→ 修复高优项 → **Closed Beta**（50–200 人）。
- **不建议直接 Open Beta**：无自动备份、恢复无 schema 校验、无自动化测试/CI、老用户不自动拉新卡、新模块（心愿单/借还/购买清单）上线时间短未经大规模实战。

## Beta 前必须修复（阻塞项）

1. **数据安全兜底（M02/M03，最高优先级）**
   - 提供「一键导出完整数据包」（DB + 完整收藏 CSV + 卡组 JSON + 设置说明）。
   - 启动时检测「距上次备份 >7 天」给一次提醒。
   - 恢复前校验备份文件（可打开、含关键表），失败明确报错且不覆盖现有库。
2. **卡柜抽屉卡片移除补确认（M05）**：`[sectionId]/edit` 页三处移除操作加 `confirmAction()`。
3. **手动同步行为说明 + 快速入口**：确保新卡数据可被用户发现（设置页已有「检查更新」，Beta 须知注明；若时间允许，加启动静默检查 M06）。
4. **补齐高频导出失败的 toast（M08 最小集）**：卡组详情页 PDF/图片/QR 导出失败给出提示。
5. **反馈通道落地**：把设置页飞书反馈文档替换/补充为「Beta 反馈模板」（含版本号、操作路径、日志导出步骤），保证问题可定位。

## Beta 期间可以接受的问题

- 新功能交互细节不顺手（心愿单/借还/清单编辑）——收集反馈迭代。
- 清单状态与库存的「手动刷新」语义（M04）：写进须知，Beta 内观察是否有大量误操作。
- 大陆网络下卡图加载慢/失败（已有 fallback + 下载进度/通知）。
- 大数据量下缺卡/清单查询变慢（关注并上报）。
- 个别页面静默失败路径（M08 其余部分）——请用户配合日志复现。
- 未实现多设备同步——用备份/导出流程替代，Beta 内验证该流程是否够用。
- 无自动更新——新包人工分发。

## Beta 不建议开放的功能

- **TTS 联动**：依赖外部 Tabletop Simulator，且 Rust `send_to_tts` 无超时 + 遗留 `unwrap()`；默认关闭，Beta 不宣传。
- **Web（非 Tauri）模式**：同步/日志/文件能力降级明显，Beta 以桌面包为准。
- **Android 包**：若未完成目标机回归，Beta 不开放移动端；`scanner`/`sharekit`/SAF 相关需单独验证。
- **多设备同步**：未实现，勿宣传。

## Beta 用户需要知道的事项

1. **数据只在本机**：换设备/重装前必须先「设置 → 备份数据库」或用一键导出；Beta 期间养成备份习惯。
2. **恢复的约束**：备份仅保证同版本恢复，恢复前会校验；误操作可能覆盖现有数据，恢复前留意确认提示。
3. **新卡数据更新**：老库不会自动拉新，需去「设置 → 关于 → 检查更新」（首次安装/清库会自动全量同步）。
4. **购买清单与收藏的关系**：在清单内标记「已购买」会写回收藏；但**直接改收藏不会自动重算清单**，请在清单页点「刷新/保存」。
5. **借还影响缺卡计算**：借出的卡会被视为「暂不可用」，借入会补足缺口，记得及时标记归还。
6. **卡柜**：抽屉内移除卡片没有二次确认，留意别误点。
7. **隐私**：应用不联网上报任何数据；备份文件包含联系人（微信/QQ/电话）等私密信息，请勿外传。
8. **反馈**：通过设置页反馈文档提交，附版本号（0.8.5）与操作路径；日志在「设置 → 查看日志」，复现问题后请导出。

## 建议收集的反馈指标

| 指标                                             | 目的           |
| ------------------------------------------------ | -------------- |
| 缺卡检查准确率（print / card 两种模式）          | 核心正确性     |
| 购买清单生成/刷新次数 + bought 写回成功/失败率   | 核心闭环验证   |
| 借出/借入创建、归还次数与逾期率                  | 借还模块活跃度 |
| 「标记已拥有 / 已购买」写回收藏的对账异常数      | 状态同步健康度 |
| 数据丢失 / 误删 / 恢复失败事件数                 | 数据安全监控   |
| 备份操作次数与距上次备份天数分布                 | 兜底习惯       |
| 崩溃 / 白屏日志（经反馈渠道 + log-service）      | 稳定性         |
| 首次同步耗时、同步失败率、手动「检查更新」使用率 | 内容分发健康度 |
| 卡图加载失败率 / 批量下载完成度                  | 资源可用性     |
| 搜索零结果率                                     | 搜索质量       |
| NPS / 试用后访谈                                 | 整体留存与方向 |
