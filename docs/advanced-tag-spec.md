# 进阶标签规范（Advanced Tag Spec）

## 1. 定位与边界

`advanced_tag` 刻画卡牌效果的**机制结构**（做什么、何时做、对谁做、代价是什么），与 `keyword`（卡面自带关键词）互补，不重复标注 keyword 本身（强攻/坚守/法盾/游走/壁垒/迅捷/反应/待命/绝念/预知/洞察/瞬息/鼓舞/回响/疾速/眩晕/增益/强力/灵便/装配/百炼/燃烧/强化/流转/狩猎/等级/获得 等均不在此列）。

## 2. 打标原则

- **全部命中**：一张牌挂 3~12 个标签，效果文本出现的每个机制都记。
- **前缀分组**：`组前缀·名`，同一组内互斥（同维度不重复）。
- **判定以文本线索为准**（每标签附线索与示例）。
- **「本回合内 S+」临时增强** 与 **常驻/永久增强** 分开标注。

## 4. 使用说明

- 标签以 JSON 字符串数组形式写入 `cards_base.advanced_tag`，与 `tag`/`keyword` 列结构一致。
- 过滤/搜索依赖 `filter_options.advanced_tags` 去重聚合，新增标签入库后需刷新该表。
- 同一标签在组内不重复；多段同类效果（如多段单体伤害）仍只标一次。
