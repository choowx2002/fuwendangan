# 回放对战棋盘 UI 布局设计

> 适用范围：`src/routes/replay/[key]/+page.svelte` → `ReplayViewer.svelte`（棋盘主视图）+ `ReplayBoard.svelte`（玩家半区）
> 最后更新：流体 flex 布局（去掉固定 1280×720 与 transform 缩放）+ 竖屏自适应

## 1. 底层技术方案

### 1.1 流体 flex 布局（自适应填满窗口，无像素缩放）

- `.viewer`（`fixed inset:0`）为 flex 纵排；`.board`（`flex:1`）填满可用区，内部三个 band 用 flex 按比例分布：敌方半区 / 共用战场行（画面核心）/ 我方半区。
- **不再使用固定 1280×720 画布与 `transform: scale`**，无缩放发虚、无 letterbox，随窗口任意宽高自适应。
- 半区内容（手牌/资源行、卡宽）由缩放因子 `k`（半区高 / 150 基准）驱动，随可用高度等比缩放。
- 战场槽 `aspect-ratio: 1039/744` + 容器查询 `min(96cqh, (100cqw-8px)/2 × 744/1039)`，同时适配宽、高并居中。
- 目标箭头层按容器像素（动态 viewBox）定位；悬停提示按指针 client 坐标定位。

### 1.2 竖屏自适应（不再拦截）

- `portrait = window.innerWidth < window.innerHeight`，为 `.board` 加 `portrait` 类。
- 竖屏下战场行 `flex-direction: column` 上下叠放、上下半区压到各 18%、连锁区隐藏避免遮挡。

### 1.3 双层级结构

| 层级   | 定位                    | 缩放              | 内容                                                       |
| ------ | ----------------------- | ----------------- | ---------------------------------------------------------- |
| **视口层** | `fixed` 于视口         | ❌ 不缩放（可点） | 顶部一行、底部底栏、右栏书签、叙述浮层、终局浮层          |
| **棋盘层** | `.board`（flex:1）     | ✅ 随窗口自适应    | 双方半区 + 共用战场行 + 目标箭头 + 悬停提示                |

## 2. 完整布局（纵向三 band，随窗口自适应）

```
.viewer (fixed inset:0, flex column)
├── .top-row        视口层：敌方信息 | 工具栏 | 我方信息 (fixed top)
├── .board          flex:1，纵向三 band
│   ├── .board-half-opp    敌方半区   flex: 0 0 28%（竖屏 18%）
│   ├── .bf-row            共用战场行  flex: 1 1 44%（竖屏改纵向叠放）
│   │     [战场1 1039:744] [战场2 1039:744] [附加槽?]   横屏并排居中
│   └── .board-half-self   我方半区   flex: 0 0 28%（竖屏 18%）
└── .bp-bar          视口层底栏 (fixed bottom)
```

## 3. 画布内区域明细

### 3.1 敌方半区（y 40–190，150px）— 镜像上半

| 行     | 高度  | 内容                                                                      |
| ------ | ----- | ------------------------------------------------------------------------- |
| 手牌行 | 78px  | 牌背叠放（`handCards.slice(0, 5)`，负 margin 错位），数量标签 `手牌（n）` |
| 资源行 | 68px  | `[传奇][选定][符文区][基地][废牌堆][放逐区]`                              |

### 3.2 共用战场行（y 196–496，300px）— 不镜像、双方共用、画面核心

| 区       | 说明                                                                                 |
| -------- | ------------------------------------------------------------------------------------ |
| 战场1 槽 | `battlefieldA`：`aspect-ratio: 1039/744`，背景 = 敌方战场卡图（等比完整显示）；槽内上/下两半分别显示**双方**在该战场的卡 |
| 战场2 槽 | `battlefieldB`：同战场1，背景 = 我方战场卡图                                        |
| 附加槽   | `battlefieldC` / `battlefieldToken` 有卡时自动追加第三窄槽（90px，不丢数据）         |

### 3.3 我方半区（y 502–652，150px）— 镜像下半

| 行     | 高度  | 内容                                                                                                         |
| ------ | ----- | ------------------------------------------------------------------------------------------------------------ |
| 资源行 | 68px  | 同敌方资源行                                                                                                 |
| 手牌行 | 78px  | 弧形排列（每张 `rotate(±5°·i) + translateY`），hover 单张 `rotate(0) translateY(-14px) scale(1.16)` 上浮放大 |

> 镜像规则：敌方 = 手牌在上、资源在下；我方 = 资源在上、手牌在下（手牌行都朝各自玩家）。

### 3.4 资源行六元素（规则 508 参考）

| 元素         | 实现                                                                  |
| ------------ | --------------------------------------------------------------------- |
| 传奇         | 独立卡槽（竖卡 60px，hover/点击可预览；空位虚线占位）                 |
| 选定（英雄） | 独立卡槽（与传奇**分开**展示）                                        |
| 符文区       | `flex:none` **按卡数动态计算宽度**，`runeAreaCards.slice(0, 12)` 上限 |
| 基地         | `flex: 1 1 auto` **占比最宽**，accent 内发光矩形底座（88px 高）       |
| 废牌堆       | 折叠卡堆（牌背 50px + 数量角标），**点击弹 `CommonModal` 卡牌列表**   |
| 放逐区       | 同上                                                                  |

### 3.5 战场背景

- 战场槽固定 `aspect-ratio: 1039/744`，与战场卡图横版尺寸一致，**等比完整显示不裁切**（画面核心）
- 背景容器 `.bf-bg`：`background: url('/black.jpg') center / cover`（**无本地图时显示黑色卡背图**，非蓝色）
- 有本地战场图（`selectedBattlefield` → `nameMetas` 解析）时 `CardSimpleImage isLandscape`（横版 1040/744）铺满该槽（与 1039/744 差异 <0.1%，可忽略）
- 35% 暗化遮罩保证卡牌可读；**不显示战场名字标签**

## 4. 视口层元素明细

### 4.1 顶部一行（`.top-row`，fixed top:8）

```
[敌方信息面板]  [工具栏]  [我方信息面板]
```

- **信息面板**（`.top-info`，毛玻璃 36px 高，`max-width: 300px`）：玩家名 · 行动徽章 · 比分 · 能量 · 法力 · 传奇经验
  - 数据源：`playerNums()`（`board.score / floatingEnergy / floatingPower / legendXp`）
  - 窄屏（≤768px）：宽度收至 `26vw` 并隐藏资源 pills，只保留名字 + 比分
- **工具栏**（`.toolbar`，毛玻璃胶囊）：返回 · 房间号 · 右栏（书签）开关 · 全屏

### 4.2 底部底栏（`.bp-bar`，fixed bottom:10 居中，`width: min(940px, 94vw)`）

| 段                       | 内容                                                                         |
| ------------------------ | ---------------------------------------------------------------------------- |
| 对局信息（`.bp-meta`）   | 赛制/时长/会话徽章 · 先手选择者（可改）· 局数 tabs                           |
| 播放控制（`.transport`） | 跳转/步进/播放/快进/倍速 · 节奏滑杆 · 进度条 · 帧号/阶段/回合 · 对局记录开关 |
| 连锁（`.bp-chain`）      | `chainEntries` 小卡横排（nowrap 压缩），hover/点击可预览或固定进阅读器       |

- 窄屏（≤768px）：隐藏 `.bp-meta` 行，只留播放控制，减少对画布遮挡

### 4.3 右栏书签（`.side-col`，默认收起）

- 关键帧书签列表（回合/阶段/得分变化，最多 200 条），工具栏按钮展开

### 4.4 其他浮层

- **阅读器弹卡**（`.card-pop`，画布内 right/bottom）：hover 或点击棋盘卡牌时弹出 `ReplayCardReader` 大卡预览（250px 宽，随画布缩放），点击关闭解除固定
- 叙述浮层（`.narration-overlay`）：对局记录，右侧滑出
- 终局浮层（`.end-overlay`）：标记胜/负/平

## 5. 交互设计

| 交互                  | 行为                                                          |
| --------------------- | ------------------------------------------------------------- |
| 棋盘卡牌 hover        | 右侧弹卡预览（画布内）                                        |
| 棋盘卡牌 click        | 弹卡固定（阅读器常驻显示，可关闭）                            |
| 废牌堆 / 放逐区 click | `CommonModal` 居中弹窗展示该区卡牌网格（可点击固定进阅读器）  |
| 手牌 hover（我方）    | 单张上浮放大（`rotate(0) + translateY(-14px) + scale(1.16)`） |
| 卡牌 hover（通用）    | accent 色 outline 高亮                                        |
| 播放快捷键            | 空格 播放/暂停、←/→ 步进、Home/End 跳转、Esc 退出全屏同步     |

## 6. 响应式与多端适配

| 场景        | 表现                                                                                          |
| ----------- | --------------------------------------------------------------------------------------------- |
| 桌面 1080p+ | scale ≥ 1，画布放大，棋盘观感最佳                                                             |
| 桌面 720p   | scale = 1，1:1 展示                                                                           |
| 手机横屏    | scale ≈ 0.54：画布整体缩小但布局一致；视口层工具栏/底栏不缩放保持可点；底栏自动隐藏对局信息行 |
| 手机竖屏    | 全屏拦截提示"请横屏游玩"，画布隐藏                                                            |

## 7. 主题与样式规范

- 画布底色：`linear-gradient(var(--bg-secondary), var(--bg-primary))` + accent 光晕（`radial-gradient`），**深浅主题自适应**（`[data-theme='dark']` 变量自动生效）
- 面板毛玻璃：`color-mix(in srgb, var(--surface) 60–88%, transparent)` + `backdrop-filter: blur(8–14px)` + `1px solid var(--border-color)`
- 状态色：胜 `#16a34a` / 负 `#dc2626`（信息面板内不适用，能量绿 `#128378`、法力橙 `#d9730d`、比分 敌方红 `#e05252` / 我方蓝 `#4d9de0`）
- 无 `overflow: auto/scroll`（除 `CommonModal` 内部列表滚动与书签列表）
