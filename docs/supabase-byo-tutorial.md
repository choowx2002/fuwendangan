# 用户教程：用你自己的 Supabase 免费版项目同步玩家数据

Rune Archive 支持把收藏、卡组、心愿单、借还、联系人、购买清单、对局、卡柜、自定义打印与设置同步到**你自己的 Supabase 免费版项目**，实现多设备互通。数据由 RLS 保护，只属于你登录的账号。

> 前置：需要注册一个 Supabase 账号（免费）。数据量很小，免费版配额完全够用（见文末「免费版须知」）。

---

## 第 1 步：创建 Supabase 项目

1. 打开 https://supabase.com/dashboard 并登录（用邮箱注册即可）。
2. 点 **New project**。
3. 填项目名称（随意，如 `rune-archive`）、设置数据库密码、选离你近的地区，点 **Create new project**。
4. 等待 1~2 分钟初始化完成。

## 第 2 步：运行建表 SQL

1. 进入项目后，点左侧 **SQL Editor** → 点 **New query**。
2. 回到 Rune Archive「设置 → Supabase 云同步（BYO）」，点 **复制建表 SQL**。
3. 把复制的内容粘贴到 SQL Editor，点 **Run**（或 Ctrl+Enter）。
4. 看到 `Success. No rows returned` 即成功。

这段 SQL 会创建一张 `user_sync_bundle` 表并开启行级安全（RLS），保证只有你自己的账号能读写你的数据。

## 第 3 步：获取 URL 与 anon key

1. 左侧 **Settings → API**（或 Project Settings → API）。
2. 复制 **Project URL**（形如 `https://xxxx.supabase.co`）。
3. 复制 **anon public key**（一长串 `eyJ...`）。

## 第 4 步：在 App 里配置并登录

1. 打开 Rune Archive「设置 → Supabase 云同步（BYO）」。
2. 粘贴 **项目 URL** 与 **anon public key**。
3. 点 **测试连接**，应提示「连接正常，尚未登录」（若提示未建表/暂停，见文末排查）。
4. 在下方填写**邮箱 + 密码**并点**登录**。
   - 如果还没在该项目创建过账号：请先到 Supabase Dashboard → **Authentication → Users** → **Add user**，创建该邮箱账号（或开启邮件验证后用邮件注册）。
   - 各设备请用**同一个邮箱账号**，这样才能跨设备同步。
5. 登录后点 **立即同步**。首次会把你当前全部玩家数据上传到云端。

## 第 5 步：第二台设备

1. 在第二台设备上重复第 4 步（同一个项目 URL / anon key / 同一个账号）。
2. 点 **立即同步**：App 会先拉取云端数据合并到本机，再上传合并结果。
   - 冲突按「修改时间新者胜；时间相同按设备号决胜」自动解决。
3. 之后任何设备改了数据，点一次「立即同步」即可双向收敛。

> 提示：想随时离线迁移，也可以用「玩家数据同步」里的「导出/导入同步包」；Supabase 与同步包互相独立、可混用。

## 免费版须知

- **数据库 500MB**：玩家数据远用不满，放心用。
- **闲置 7 天自动暂停**：免费项目连续 7 天无访问会被暂停，期间同步会失败。到 Dashboard 打开项目点 **Restore** 即可恢复。
- **恢复后 URL 可能变更**：暂停恢复后项目 URL 偶尔会变，若同步报连接失败，请回 Dashboard 核对 API 里的新 URL 并更新。
- **带宽/请求**：App 会在数据没变化时跳过上传（省配额）；建议不要高频点击同步，正常使用即可。
- **安全**：URL 与 anon key 只保存在本机；数据被 RLS 限制为仅你的账号可访问。请勿把 anon key 泄露给他人（会暴露你的项目地址）。

## 排查

| 现象                         | 处理                                                                     |
| ---------------------------- | ------------------------------------------------------------------------ |
| 测试连接提示「云端尚未建表」 | 第 2 步的 SQL 没跑或没跑成功，重新复制运行                               |
| 测试连接提示暂停/连接失败    | 免费项目已暂停或 URL 变了：到 Dashboard 恢复项目并核对 URL；或检查网络   |
| 登录失败                     | 确认项目已建好表；在 Dashboard → Authentication 创建账号；密码错误请重设 |
| 同步提示无权限               | 确认登录成功后再同步；确认建表 SQL 完整运行（含 RLS 策略）               |
| 某张卡导入后不见了           | 本地内容库比云端旧，卡图已下架所致，属预期行为（以本地最新内容库为准）   |
