# 缺失功能与风险清单

> 基于代码证据。按优先级分组，标注 Beta 是否必须、可否延后。

## 高优先级（Beta 前建议修复）

| 缺失 / 风险                                                                                                                                | 为什么重要                            | Beta 必须                          | 可否延后   |
| ------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------- | ---------------------------------- | ---------- |
| **新功能删除无确认**：心愿单 / 借还记录 / 购买清单（含条目）的删除按钮直接执行，未用 `ask()`；与现有功能（settings、decks 均带确认）不一致 | 误点即丢记录，借还/清单属不可逆操作   | **必须**                           | 否         |
| **三表状态不同步**：购买清单「已买到」不写回收藏库存；心愿单「标记已拥有」不写入 `collection`                                              | 用户会困惑「买到了/标记了但收藏没变」 | **必须**（至少提示，推荐一键写回） | 可部分延后 |
| **`/simulator` 侧边栏死链**（Sidebar 有导航项，无对应路由）                                                                                | 点击 404，Beta 观感差                 | **必须**                           | 否         |
| **数据仅本机、无同步**：多设备同步未实现                                                                                                   | 重装/换机前若无备份则全部丢失         | **必须**（Beta 须知 + 强调备份）   | 否         |
| **备份/恢复可用性验证**：复制 db 文件流程未做端到端验证                                                                                    | 若备份不可用则数据无兜底              | 必须（测试通过）                   | 否         |

## 特别风险项核验

- **数据丢失**：有备份/恢复 + 各清空操作带确认 → 风险可控；**新功能删除无确认 → 已列高优**。
- **重复插入购买清单**：**已处理**。条目 `UNIQUE(list_id, card_no, card_no_extend, language_pref, finish_pref)` + `ON CONFLICT` upsert；`refreshPurchaseListFromDeck` 切换模式时清理键冲突旧条目。
- **借出归还影响可用库存**：**已实现**。`getActiveLoanQty` 计入 `checkDeckOwnership`（active/overdue 生效，returned/lost/cancelled 不计）。
- **心愿单 / 购买清单 / 库存状态同步**：**存在缺口（见高优）**。
- **空数据**：各页 EmptyState + loading 覆盖 → 已处理。
- **错误提示**：全局 toast + 各页面 try/catch 失败分支 → 已处理。
- **用户反馈渠道**：设置页外链反馈文档 → 已有。
- **隐私**：无遥测/分析 SDK；Supabase 用 publishable key；`.env.local` gitignored → 无隐私红线；多设备同步若启用需提示 anon key 公开性（`docs/player-data-sync.md` 已列风险）。
