## 范围说明

- **多设备同步（M01）✅ 已实现**：`docs/player-data-sync.md` 按 v2 落地——手动 Sync Bundle（全实体 + 设置白名单 + 墓碑）与 Supabase BYO 云同步（用户自建免费版项目 + 邮箱密码 + RLS，单 JSON 行整包）。Git 传输已永久放弃。换机/重装仍可由「一键完整数据包 + 恢复前校验」覆盖（含内容库副本）。
- **卡图 ZIP 导入已实现**：设置 → 本地卡图缓存 →「导入卡图 ZIP」，选择 .zip（应用自身缓存导出格式）自动匹配 `card_prints` 并导入缺失卡图（匹配优先级：应用缓存精确名 → printCacheName → card_no_extend；已存在跳过）。

## 已解决

### M09 借还 / 联系人 CSV 导出（✅ 已解决）

- 证据：`src/lib/collection/loan-csv.ts`（`buildLoansCsv` / `buildContactsCsv`，复用 `buildCsv`）；`/collection/loans` 页 topbar「导出」动作 + 弹窗两个选项（借还记录 CSV / 联系人 CSV），借还导出当前筛选结果（含联系人名/状态/工艺本地化文案）；i18n `loans.export*`。

### M12 规则列表 / 系列收藏页空状态（✅ 已解决）

- 证据：`/rules` 页 `docs` 为空时渲染空态提示（`rules.empty`）；系列收藏页由 `CollectionGrid` 内置 `EmptyState` 兜底。

## 已确认不需要（从范围移除）

- **应用自动更新**（原 M11 / F174）：无 `tauri-plugin-updater`；Beta 人工分发新包即可。
- **借还到期系统推送通知**（原 F55）：保留应用内角标/汇总，不做系统推送。
- **购买清单 CSV 回导**（原 F98）：仅保留导出。
- **应用内反馈表单 / 崩溃上报**（原 F161）：沿用设置页飞书文档链接 + 本地日志。
- **收藏重做**（原 F190 缺项）：仅保留撤销。
